This catches common mistakes; it is not a full security review. It reads files only, so settings you changed in the Supabase dashboard aren't visible here. Supabase's own Security Advisor (Dashboard → Advisors) checks the live database. Use both.

How to get your project folder

  1. Lovable: connect GitHub (top right → GitHub), open the repository on github.com, then Code → Download ZIP.
  2. Bolt / Replit / Cursor: download or export the project as a ZIP.
  3. Double-click the ZIP to unpack it, then choose that folder above.

The check needs your supabase/migrations folder for the database part. If you have the Supabase CLI, supabase db dump --schema public > schema.sql inside the folder gives it the latest database setup.

If it finds a secret key

Change the key first (Supabase: Project Settings → API; Stripe: Developers → API keys; OpenAI and others: their API key pages). Removing it from the code is not enough, because the old key is already out.
